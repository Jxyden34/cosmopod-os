# Security policy

Cosmopod OS is pre-release. No version is production-supported yet.

Report vulnerabilities privately through GitHub's
[security-advisory form](https://github.com/Jxyden34/cosmopod-os/security/advisories/new).
Do not open a public issue containing credentials, signing keys, device tokens,
private device data, or exploitable fleet details.

Include affected commit/version, reproduction steps, impact, and a safe contact
method. Do not test against devices or infrastructure you do not own or have
explicit permission to assess.
